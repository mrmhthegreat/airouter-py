## Quick links

- **Install**: `pip install airouter-py` or `pip install airouter-py[server]`
- **PyPI**: <https://pypi.org/project/airouter-py/>
- **Live API docs**: hosted on GitHub Pages after you enable it (see [HOSTING.md](HOSTING.md))
- **CLI help**: `airouter --help` after install
- **Source**: <https://github.com/mrmhthegreat/airouter-py>
