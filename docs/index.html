HTTP API Reference

The HTTP API exposed by the airouter package — a router across free-tier AI providers (Groq, Gemini, OpenRouter, Z.AI, SambaNova, Ollama, any OpenAI-compatible URL) with automatic failover for text, TTS and STT. Server built with Starlette via airouter.server.new_handler(...).

Base URL
http://localhost:8080
Tenant auth
Authorization: Bearer air_<48 hex>
Admin auth
Authorization: Bearer $AIROUTER_ADMIN_TOKEN
OpenAI-compatible
Point any OpenAI SDK at /v1

Source of truth: airouter/server.py, airouter/types.py, airouter/router_status.py, airouter/preset.py. If this document and the code disagree, the code wins.
